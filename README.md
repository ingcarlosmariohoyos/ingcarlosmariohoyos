<h1>👋 Hola, soy Carlos Hoyos | Ingeniero de Datos</h1>

Me apasiona convertir datos en valor real. Disfruto construyendo pipelines de datos eficientes, modelando información para que tenga sentido, y creando visualizaciones que ayuden a tomar mejores decisiones.

Trabajo con **Python (Pandas, Polars)**, **SQL (Oracle, PostgreSQL)**, **AWS**, **dbt**, **Dagster** y **Power BI** — desde la ingesta y transformación de datos hasta data warehouses completos y dashboards interactivos.

Me interesa especialmente la ingeniería de datos en la nube, el modelado dimensional y la orquestación de pipelines escalables.

<h2>🌟 Proyectos Destacados</h2>

**Marketplace DW — Data Warehouse con Arquitectura Medallion**
Tecnologías: Python (Pandas, SQLAlchemy), dbt, Dagster (Dagster Cloud), PostgreSQL (Supabase), Docker

Data warehouse completo para un marketplace tipo e-commerce, con arquitectura medallion (Bronze → Silver → Gold):
+ Ingesta y carga de datos crudos a la capa Bronze.
+ Modelado dimensional en dbt: staging y esquema en estrella (`fact_orders` + 5 dimensiones) con integridad referencial.
+ Orquestación basada en assets con Dagster (Dagster Cloud, plan Serverless) y schedule diario automatizado.
+ Desplegado 100% en la nube (Supabase + Dagster Cloud), con documentación completa y diagramas de arquitectura.

Repositorio: https://github.com/ingcarlosmariohoyos/marketplace_dw_project

**Pokémon Analytics — Análisis Exploratorio y Visualización**
Tecnologías: Python (Pandas, NumPy, Matplotlib), Power BI

Proyecto de análisis descriptivo y exploratorio del universo Pokémon:
+ Limpieza, transformación y preparación del dataset.
+ Análisis comparativo de estadísticas base (ataque, defensa, velocidad, etc.).
+ Visualizaciones con Matplotlib y dashboard en Power BI.

Repositorio: https://github.com/ingcarlosmariohoyos/Pokemon_analitycs
